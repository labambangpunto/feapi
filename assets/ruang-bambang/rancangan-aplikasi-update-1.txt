saya sedang ingin mengembangkan aplikasi sederhana pencatat keuangan pribadi. aplikasi ini hanya untuk diri saya sendiri. fitur-fiturnya adalah:
terdiri dari 4 tab utama dengan style bottom navigation:
# Home
di tab home, akan menampilkan hal-hal berikut
1. greeting
2. total saldo
3. total pengeluaran dan total pemasukan
4. saldo masing-masing akun
5. grafik dan analisis tambahan

# Transaksi
di tab transaksi, akan menampilkan hal-hal berikut
1. log transaksi
2. ada tombol plus (+), untuk menampilkan 3 opsi pengisian form, yaitu form transaksi pengeluaran, pemasukan dan transfer antarakun
3. fitur jump to page
4. fitur filter log transaksi
5. fitur edit transaksi dan hapus transaksi

# Utang
di tab utang, akan menampilkan hal-hal berikut
1. ada dua tab, yaitu tab "Utang" dan tab "Piutang"
2. tab "Utang" menampilkan list Utang. tab "Piutang" menampilkan list Piutang.
3. untuk melunasi utang atau piutang: tekan satu list utang atau piutang, lalu akan muncul popup konfirmasi sebuah form pelunasan.
3. ada tombol plus (+), untuk menampilkan 2 opsi pengisian form, yaitu form Utang dan Form Piutang.
4. di tab "Utang" dan "Piutang" punya fitur jump to page
5. di tab "Utang" dan "Piutang" punya fitur edit dan hapus utang atau piutang.

# Atur
di tab atur (pengaturan), akan menampilkan hal-hal berikut
1. edit profil (kinkron dengan gdrive API)
2. login google drive (google drive API)
3. logout google drive (google drive API)
4. mode gelap / terang
5. kelola akun: membuat akun baru dan mengisi saldo awal
6. kelola label: membuat label baru
7. backup / restore JSON (terenkripsi)
8. ekspor CSV (agar bisa dibaca dengan aplikasi excel)
9. danger zone: reset seluruh database. keamanannya dengan 2 kali verifikasi dengan metode berbeda.

## Form untuk transaksi
### Form Pengeluaran
form pengeluaran berisi fields:
1. "Nominal (Rp)": dengan prefix tulisan "Rp" dan formatting, yaitu setiap 3 angka diberikan titik. tujuannya untuk keterbacaan
2. "Biaya tambahan (opsional)": dengan prefix tulisan "Rp" dan formatting, yaitu setiap 3 angka diberikan titik. tujuannya untuk keterbacaan. Biaya tambahan otomasis dianggap pengeluaran
3. "Kuantitas (Qty)": default bernilai 1
4. "Akun sumber": berbentuk dropdown, dan ada opsi untuk menambahkan akun
5. "label / tag": berbentuk chip atau capsule, dan ada opsi untuk menambahkan label
6. "tanggal dan waktu": secara default menggunakan tanggal dan waktu saat itu
7. "Catatan / deskripsi"
field yang wajib diisi adalah "Nominal (Rp)", "Akun sumber", "label / tag", "tanggal dan waktu" dan"Catatan / deskripsi"
