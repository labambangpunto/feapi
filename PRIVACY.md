### PRIVACY POLICY (KEBIJAKAN PRIVASI)

Terakhir diperbarui: Selasa, 29 September 2026

Feapi Personal Finance Tracker dibangun dengan prinsip _"Privacy by Design"_. Kebijakan ini sangat singkat karena arsitektur tekniknya memang dirancang demikian:

1. Kami TIDAK Mengumpulkan Data Pribadi

- Aplikasi ini berjalan sepenuhnya offline di perangkat Anda.

- Tidak ada koneksi ke server pusat, cloud, atau infrastruktur eksternal mana pun.

- Tidak ada telemetri, analitik, pelacakan, atau pengiriman log error ke pihak manapun.

- Tidak ada cookie, pixel pelacak, atau SDK pihak ketiga yang mengumpulkan data.

2. Di Mana Data Anda Tersimpan?

- Semua data yang dibuat atau disimpan oleh Aplikasi (misalnya dokumen, pengaturan, atau riwayat) tersimpan hanya di penyimpanan internal perangkat Anda.

- Pengembang Aplikasi tidak memiliki akses, tidak pernah akan memiliki akses, dan secara teknis tidak mampu membaca data tersebut dari jarak jauh.

- Jika Anda menghapus Aplikasi dari perangkat Anda, semua data terkait juga akan hilang (kecuali jika sistem operasi Anda menyimpan cache sementara, yang merupakan perilaku standar OS, bukan tindakan aplikasi).

3. Keamanan & Tanggung Jawab Pengguna

- Karena data hanya ada di perangkat Anda, keamanan data bergantung pada keamanan perangkat Anda (password layar, enkripsi disk, dll.).

- Kami tidak bertanggung jawab atas pencurian fisik perangkat Anda atau akses tidak sah oleh orang lain yang memegang perangkat Anda.

- Disarankan untuk menggunakan proteksi perangkat standar (PIN, Biometrik, Enkripsi Disk) untuk melindungi data sensitif.

4. Mengapa Tidak Ada Server?

- Desain ini dipilih sengaja untuk memastikan otonomi penuh pengguna.

- Tanpa server, tidak ada risiko kebocoran data massal (_data breach_), sensor, atau penyalahgunaan data oleh pengembang/pemilik layanan.

- Pembaruan Aplikasi hanya dilakukan melalui mekanisme distribusi terbuka (GitHub/Store) dan tidak melibatkan transfer data pribadi.

5. Hak Anda
   Karena kami tidak menyimpan data Anda di tempat manapun selain perangkat Anda sendiri, hak-hak seperti "akses data", "koreksi data", atau "penghapusan data" dipegang sepenuhnya oleh Anda melalui kontrol sistem operasi perangkat Anda.

6. Perubahan Kebijakan
   Jika di masa depan kami menambahkan fitur yang memerlukan konektivitas internet (yang saat ini tidak direncanakan), kami akan:

- Memberi tahu Anda secara jelas sebelum rilis.

- Memperbarui kebijakan privasi ini.

- Meminta persetujuan eksplisit Anda sebelum mengumpulkan data apa pun.

- Hingga saat itu, komitmen "Zero Data Collection" ini tetap berlaku.
